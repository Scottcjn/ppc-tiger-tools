# Contributing to PPC Tiger Tools

Tools for Mac OS X Tiger/Leopard on PowerPC G4/G5.

## Development Setup

```bash
git clone https://github.com/MingYu5/ppc-tiger-tools.git
cd ppc-tiger-tools
```

## Supported Systems

- Mac OS X Tiger (10.4) PowerPC
- Mac OS X Leopard (10.5) PowerPC
- G4 and G5 Macs

## Contributing

1. Fork the repo
2. Create a feature branch
3. Test on real hardware when possible
4. Open PR against `Scottcjn/ppc-tiger-tools:main`

Questions? Open an issue!
